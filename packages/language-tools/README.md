# @multifront/language-tools

Editor tooling for multifront component files: the Volar language plugin that turns each block into code the TypeScript and CSS language services read, and the language server (`multifront-language-server --stdio`).

Part of [multifront](https://github.com/MionKit/multifront): one component file, three frameworks.

> **Status:** early development, not published yet.
