# @multifront/vite

Vite plugin for multifront component files: hands each target to `@vitejs/plugin-vue`, `@vitejs/plugin-react` or
`@sveltejs/vite-plugin-svelte`, and builds one package per framework with `mf-build`.

Part of [multifront](https://github.com/MionKit/multifront): one component file, three frameworks.

> **Status:** early development, not published yet.
