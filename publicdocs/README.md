# multifront

Write one component file with a Vue, a React and a Svelte version side by side, and styles they all share. multifront builds its React version with Vite, and VS Code understands the whole file.

## Pages

- [Getting Started](01-getting-started.md): the Vite setup and a first component.
- [Component Files](02-component-files.md): the blocks of a `.ucf` file and their rules.
- [Styles](03-styles.md): style blocks, `$style` and scoped styles across components.
- [Imports](04-imports.md): which framework an import of a `.ucf` file gets.
- [Editor Setup](05-editor-setup.md): the VS Code extension and what it does.
- [Errors](07-errors.md): every error code and its fix.
