# multifront

Write one component file with a Vue, a React and a Svelte version side by side, and styles they all share. multifront compiles it for each framework, so you can publish one UI library to all three.

## Pages

- [Component Files](02-component-files.md): the blocks of a `.ucf` file and their rules.
- [Imports](04-imports.md): which framework an import of a `.ucf` file gets.
- [Editor Setup](05-editor-setup.md): the VS Code extension and what it does.
- [Errors](07-errors.md): every error code and its fix.
