# multifront

Write one component file with a Vue, a React and a Svelte version side by side, and styles they all share. multifront builds its Vue and React versions with Vite, and VS Code understands the whole file.

![Counter.ucf becomes a Vue and a React component that render the same scoped attribute and class names](assets/one-file-two-frameworks.png)
