What the Vite plugin does when an app imports a .ucf file. Shared blocks run first, then only the chosen target is compiled. The other blocks never reach the bundle.

Attribute rewrite
a post plugin, on every importer import Card from './Card.ucf' with { framework: 'svelte' } → import Card from './Card.ucf?target=svelte'

Browsers and Node reject import attributes they do not know, so the attribute moves into the id before any runtime sees the code.
