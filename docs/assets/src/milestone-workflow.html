multifront · agentic workflow

One milestone, end to end, on its own

One orchestrator runs every step of a milestone in order. A fresh agent turns each step into a todo, builds it and gets its PR green. The next step starts only once that PR is merged. One QA pass, one fixer and one docs writer close the milestone.
