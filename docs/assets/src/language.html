multifront · editor and types

The same blocks, seen by the editor

Inside a .ucf file each block gets its own colours and its own language service. Outside it, an importer gets the types of the framework it picked, with the same rules the build uses.

editor · each block becomes embedded code for an existing service
<style>→css · scss code→CSS language service
<react>→tsx code + $style→TypeScript service
<vue>→ts · html · css codes→@vue/language-core
<svelte>→ts code + html→svelte2tsx + HTML service

Every embedded code carries a map back to the block, so errors and hovers land on the right line of Card.ucf.
